GITHUB PAGES SETUP
1. Download and extract this ZIP on your phone or computer.
2. Open your GitHub repository bestlegacy-website.
3. Choose Add file > Upload files. Upload the CONTENTS of this folder (not the outer folder itself).
4. Commit changes.
5. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
6. Wait a few minutes for the published website link.
